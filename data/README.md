# 合成资料说明

`knowledge_base.json` 全部为本项目人工设计、AI 辅助生成的测试资料，不是真实公司制度。`影创 Studio` 是演示名称。D01/D02 故意保留 30 天与 15 天的冲突，日期不同但没有适用范围、优先级或废止依据。

每份文档包含 ID、标题、版本日期、范围、关键词；每个短片段包含 `chunk_id`、`policy_key`、原文 `text`。`policy_key` 表示片段讨论的同一政策事项，用于找出需要一起读取的候选资料；值本身不编码结论或优先级。

`synonyms.json` 是有限的检索扩展规则。检索使用标题/关键词权重 3、正文权重 1 的双字重叠计数，最低分 3；不使用模型向量或外部搜索。工具返回的分数只用于排序，不是置信概率。

修改 `text` 后重新运行即可改变证据与答案；程序不会读取预期输出决定答案。`examples/cases.json` 第 10、11 例生成独立的知识库快照，保留原资料，以便复现“10 → 12 天”和“冲突消失”的变化。
